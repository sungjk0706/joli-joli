# 🚀 졸리졸리 라이브 커머스 V3 개발 인계서

본 문서는 Joli-Joli 프로젝트의 라이브 커머스 기능을 모바일 환경에 최적화하여 고도화한 내역을 기록한 인계서입니다. 다음 세션의 AI 에이전트는 본 내용을 바탕으로 개발을 이어가시기 바랍니다.

## 1. 핵심 아키텍처: 계단식 3단계 뷰 시스템
사용자의 몰입도에 따라 화면이 3단계로 확장되는 `viewMode` 상태 시스템이 구축되어 있습니다.
- **SPLIT (4:6)**: 상단 영상(40%), 하단 상품 정보(60%)의 기본 CCTV 스타일.
- **PORTRAIT (세로전체)**: 영상이 100vh로 확장되며, 모든 UI는 글래스모피즘(Glassmorphism) 스타일의 투명 오버레이로 전환.
- **LANDSCAPE (가로전체)**: 화면을 강제로 90도 회전시켜 전체 화면 시청이 가능한 극강의 몰입 모드.

## 2. 기술적 최적화 (하드웨어 가속 엔진)
단순 CSS 회전의 렉을 해결하기 위해 네이티브 하드웨어 가속 로직이 적용되었습니다.
- **Native Orientation Lock**: `requestFullscreen()`과 `screen.orientation.lock()` API를 사용하여 시스템 레벨에서 제어합니다.
  - **True Fullscreen (V3.1)**: 세로 전체 모드(`PORTRAIT`) 진입 시에도 브라우저 주소창과 도구 모음을 자동으로 숨겨 몰입감을 극대화했습니다.
  - **Seamless Orientation Sync**: 가로/세로 모드 전환 시 전체 화면이 해제되지 않고 유지되도록 최적화하여 끊김 없는 시청 환경을 제공합니다.

## 3. UI/UX 주요 개선 사항
- **트리거 변경**: 상단 컨트롤 바의 **전용 확대 버튼(`Maximize2`)** 클릭 방식으로 변경하여 오작동 방지.
- **클린 뷰 (Clean View)**: 세로 전체 모드에서 불필요한 텍스트 라벨을 제거하고, 주문/좋아요 버튼을 최하단(`pb-6`)으로 밀착시켜 영상 시야를 20% 이상 추가 확보했습니다.
- **강조 효과**: 상품 미니카드를 클릭하면 10초간 테두리 강조 효과가 지속됩니다.
- **실시간 동기화**: Supabase Realtime 채널(`live-multi-sync-v5`)을 통해 실시간 송출 상품 변경 사항을 즉시 반영합니다.

## 4. 향후 과제 (Next Steps)
- **가로 모드 UI 튜닝**: 가로 전체 화면 시 상품 리스트의 위치와 크기를 더 직관적으로 조정할 필요가 있음.
- **네이티브 복구 로직 강화**: 일부 구형 브라우저에서 전체화면 해제 시 오리엔테이션이 언락되지 않는 케이스 테스트 필요.
- **장바구니 연동**: 라이브 시트 내에서 옵션 선택 및 장바구니 담기 기능 고도화.

- `src/components/customer/HeroSection.jsx`: 라이브 쇼핑하기 진입 버튼.
